# Security Log Feeds

Synthetic / public intel feeds for the Sensor Array practice SIEM.

**Public lab / learning work only.** This repository will generate sample logs and pull public intel (for example CISA KEV), normalize them, and write `latest/` artifacts for Sensor Array to load.

This is not a production pipeline and does not contain employer telemetry.
